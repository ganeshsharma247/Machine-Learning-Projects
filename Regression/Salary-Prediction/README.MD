# Salary Prediction using Linear Regression 📊

## 📌 Project Objective
The objective of this project is to predict a person’s salary based on their years of experience using Machine Learning.

---

## 📊 Dataset Information
- Features:
  - YearsExperience
  - Salary
- Dataset Source: Kaggle

---

## ⚙️ Algorithm Used
- Linear Regression

---

## 🛠️ Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## 🚀 Steps Performed
1. Loaded dataset using Pandas  
2. Defined input (X) and output (y)  
3. Trained Linear Regression model  
4. Predicted salary for new value  
5. Visualized results using graph  

---

## 💻 Code Snippet
model = LinearRegression()
model.fit(X, y)

pred = model.predict([[5]])
print(pred)

---

## 📈 Output
Predicted Salary for 5 years experience: 73042.01

---

## 📌 Conclusion
- Salary increases linearly with experience  
- Model works effectively for prediction
